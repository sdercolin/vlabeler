# 라벨러

"라벨러"는 특정한 종류의 음성합성엔진들에 맞추어 `vLabeler`의 동작을 규정하는 일종의 설정 파일이에요. 예를 들어, 내장되어 있는
`UTAU oto 라벨러`는 UTAU의 `oto.ini`를 편집하기 위한 라벨러에요.

라벨러가 정의하는 것들은 다음과 같아요:

- 엔트리들이 어떠한 데이터/필드를 필요로 하는가? (예시: UTAU의 경우, `고정자음부`, `선행자음부`, `오버랩` 등이 필요할 거에요.)
- 마커를 제어하기 위해, 데이터/필드들은 어떤 방식으로 에디터에 표시되어야 하는가?
- 엔트리들이 반드시 연결되어 있어야만 하는가? (모든 엔트리들의 시작이 이전 엔트리의 끝과 일치해야 하는가?)
- 어떠한 방식으로 `vLabeler` 프로젝트에 라벨 파일을 파싱해 올 것인가?
- `vLabeler` 프로젝트 내에서 어떻게 라벨 파일을 생성할 것인가?
- `vLabeler` 프로젝트에 속한 하위 프로젝트들은 어떻게 구축하고 관리(추가/이름 변경/제거)할 것인가?
- 그 이외에 특정 라벨 파일을 편집하는 데에 필요한 동작들은 무엇인가?

라벨러는 라벨러의 파일 그 자체를 바꿀 필요 없이, 몇몇 설정 가능한 필드들을 GUI를 통해 지원할 수 있습니다. `새 프로젝트` 창의
라벨러 선택란 옆에 있는 `설정` 아이콘을 누르면, 라벨러에서 지원하는 설정을 찾을 수 있어요.

내장 라벨러들의 목록은 [라벨러 선택하기](../getting-started/choosing-a-labeler.md)에서 확인해 주세요.

## 커스텀 라벨러

`vLabeler`가 지원하지 않는 특정 음성합성엔진의 라벨을 편집하고 싶다면, 해당 음성합성엔진을 지원하는 개발을 요청할 수도 있지만
직접 만들어 보는 것도 방법이에요 (물론 약간의 코딩 지식이 필요합니다).
라벨러 개발에 흥미가 있다면,
[커스텀 라벨러 개발(영문)](https://github.com/sdercolin/vlabeler/blob/main/docs/labeler-development.md)을 읽어 보세요.

만들어진 라벨러는 `설정` -> `라벨러 목록...`에서 불러올 수 있어요. 또한 자작 라벨러는 어디든 배포해도 좋습니다. 자작 라벨러가
내장 라벨러로 만들어지길 원한다면, 저희에게 연락해 주세요.
