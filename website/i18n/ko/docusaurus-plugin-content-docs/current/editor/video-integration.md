# 영상 통합

샘플 파일과 같은 이름, 같은 길이의 영상 파일을 추가해 편집 도중 영상을 재생할 수 있어요.

예시:

```
(샘플 폴더)
    - 1.wav
    - 1.mp4
    - 2.wav
    - 2.webm
```

**이 기능을 사용하려면 VLC가 설치되어 있어야 해요.** ([다운로드 링크](https://www.videolan.org/vlc/index.html))

([Releases](https://github.com/sdercolin/vlabeler/releases)에서 배포된 앱 이용 시) 애플 실리콘 맥의 경우,
`macOS (AppleSilicon)`이 아닌 `macOS`버전이 필요해요.

단축키 `Ctrl` + `V`나 `Ctrl` + `Shift` + `V`를 사용하면, 왼쪽 아래 모서리에서 영상을 열거나 새로운 창에서 영상을 열 수 있어요.

영상은 샘플 파일과 함께 재생되며, 무음입니다.
