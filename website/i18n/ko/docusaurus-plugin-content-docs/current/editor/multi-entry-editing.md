# 다중 편집 모드 설명서

연속 편집용 라벨러들([예시](../getting-started/choosing-a-labeler.md#working-on-audio-labels))에서는, 단일 편집 모드와 다중
편집 모드를 전환할 수 있어요. 다중 편집 모드에서는 같은 샘플 파일에 연결된 모든 엔트리들을 보거나 편집할 수 있답니다.

기본적으로 다중 편집 모드는 활성화되어 있어요. 하단 바 가운데의 `단일/다중` 버튼을 눌러 활성화하거나 비활성화할 수 있습니다.

다중 편집 모드에서는, 엔트리들의 이름이 에디터의 맨 위에 표시되요. 이름을 클릭하면 아래의 기능을 사용할 수 있어요. :

- 클릭: 엔트리 이름 변경
- 길게 클릭: 해당 엔트리로 이동

또한 `설정` -> `환경설정` -> `에디터` -> `클릭하여 엔트리로 이동`(기본값 꺼짐)을 활성화하면, 캔버스에서 엔트리의 본체를 클릭해
해당 엔트리를 현재 엔트리로 전환할 수 있어요. 경계나 마커를 클릭하면 드래그가 시작되며 현재 엔트리는 바뀌지 않아요.
