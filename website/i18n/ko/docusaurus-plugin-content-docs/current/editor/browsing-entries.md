# 엔트리 탐색하기

엔트리 목록에는 두 가지 요소가 있어요. :

1. 엔트리 목록: 기본적으로 우측에 보여져요. `외형` -> `엔트리 목록 표시`에서 숨기거나 보이게 할 수 있어요. 모든 기능을 지닌
   엔트리 필터(하단에 설명 있음)를 제공해 줍니다.
2. `엔트리 이동...` 대화창: `Ctrl` + `G`나 하단 바에서 엔트리 번호 버튼을 누르면 보여져요.
   간단한 엔트리 필터를 제공해 줍니다.

## 엔트리 필터링 및 검색

두 종류의 엔트리 목록 모두에서, 다음의 문법을 사용한 엔트리 검색을 할 수 있어요. :

```
aaa;name:bbb;sample:ccc;tag:ddd
```

`;`을 사용해 여러 개의 조건을 결합할 수 있어요. 전체 조건을 만족하는 엔트리만 화면에 보여집니다.

다음의 조건 키들 (`:`의 왼쪽)이 지원됩니다. :

- 키 없음: 엔트리 이름, 샘플 이름(확장자 제외), 태그에서 검색
- `name`: 엔트리 이름에서 검색
- `sample`: 샘플 이름(확장자 제외)에서 검색
- `tag`: 태그에서 검색

매칭 시 `포함 여부`를 기준으로 삼습니다.

더 많은 선택지들을 보려면, 엔트리 목록에서 `확장` 버튼을 누르세요.

`완료` 필터와 `중요` 필터를 선택하면, `필터 미적용`, `"완료"/"중요" 엔트리만 표시`, `"완료"/"중요" 엔트리만 제외"` 간의 상태가
전환됩니다.

모든 필터들은 `AND` 논리로 연결됩니다.

`더 보기` 버튼을 누르면, 설정 대화창이 열리며, 고급 필터링이 가능해져요.

## 여러 엔트리 선택하기

엔트리 목록에서, 여러 엔트리를 선택해 일괄 편집을 할 수 있어요:

- `Ctrl` + 클릭: 엔트리를 선택에 추가하거나 선택에서 제거해요.
- `Shift` + 클릭: 범위 내의 엔트리를 선택해요.

macOS를 사용 중이라면, 위의 `Ctrl`은 `Command`를 의미해요.

선택한 엔트리를 우클릭하면 다음 일괄 작업을 사용할 수 있어요:

- 선택한 항목을 완료/미완료로 표시
- 선택한 항목을 즐겨찾기에 추가/제거
- 선택한 항목의 태그 설정
- 선택한 항목 제거

수식 키 없이 클릭하면 선택이 해제돼요. 일괄 작업은 한 번의 `실행 취소`로 되돌릴 수 있어요.

## 에디터에서 엔트리 필터 적용하기

기본적으로 프로젝트 탐색(단축키, 마우스 스크롤, 버튼 클릭을 통한 다음 엔트리로/다음 샘플로 이동 등)은 필터 적용의 영향을 받지
않아요.

예를 들어, 필터를 적용해 엔트리 목록에서 `다섯 번째 엔트리`가 보이지 않도록 해 볼게요. 이 경우, `네 번째 엔트리`에서
`아래 방향키`를 누르면 (엔트리 목록에 `다섯 번째 엔트리`가 없음에도) `다섯 번째 엔트리`로 접근됩니다.

이 때 (확장된 메뉴에서) `연결` 버튼을 누르면, 엔트리 목록에 보여지지 않는 엔트리들을 프로젝트 탐색에서 스킵할 수 있어요. 자신이
원하는 집합의 엔트리들에게 좀 더 집중할 수 있게 되죠.

앞서 들었던 예시를 기반으로 설명하면, `연결` 버튼을 활성화한 상태에서 `네 번째 엔트리`에서 `아래 방향키`를 누르면, `다섯 번째
엔트리` 대신 `여섯 번째 엔트리`로 이동합니다.

참고로, `엔트리 이동...` 대화창은 이 연결 버튼의 영향을 받지 않는답니다. 목록에서 필터링된 엔트리로 이동하기 위해 엔트리 목록에
적용된 필터를 해제할 필요는 없어요.
