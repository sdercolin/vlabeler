# 키보드/마우스 동작 설명서

(맥 운영체제를 사용할 경우) 하단 설명에 나오는 `Ctrl`키는 `Command`키와 같은 뜻이에요.

단축키는 `설정` -> `환경설정` -> `단축키`에서 설정할 수 있어요.

## 마커 이동시키기

- 일반 마커 위에서 드래그: 마커 이동.
- 주요 마커 위에서 드래그: 모든 마커를 한꺼번에 이동.
- `Shift`: 일반 마커와 주요 마커 전환. (예시: `Shift`를 누른 채 주요 마커를 드래그하면, 주요 마커만 움직여요.)
- `Q`/`W`/`E`/`R`/... : 해당하는 마커를 현재의 커서 위치로 이동. 마커의 순서는 라벨러가 정의해요.
    - 단일 편집 모드에서는 엔트리의 모든 마커에 적용돼요.
    - 다중 편집 모드에서는 `Q`와 `W`만 사용할 수 있으며, 각각 커서 위치 엔트리의 왼쪽·오른쪽 경계를 옮겨요. 또한 `단축키`에서
      `현재 엔트리의 왼쪽/오른쪽 경계를 커서 위치에 놓기`(기본 키 없음)에 키를 지정하면, 커서 위치와 관계없이 현재 엔트리의
      경계를 옮길 수 있어요.

## 오디오 재생

- `Space`: 현재 엔트리 재생/정지.
- `Shift` + `Space`: 현재 샘플 재생/정지.
- `Ctrl` + `Shift` + `Space`: 현재 화면에 표시되는 영역 재생/정지.
- (대부분의 도구에서) 오른쪽 마우스 클릭 : 클릭된 부분 재생.
- (**커서** 도구에서) `Alt` + 마커 위에서 드래그: 커서 주변 범위에 해당하는 오디오 재생.

더 많은 내용은 [재생 도구](./tools.md#playback)에서 확인해 주세요.

## 스크롤 동작

- `Shift` + 마우스 스크롤: 수평 스크롤.
- `F`나 하단 바의 집중 버튼: 현재 엔트리가 화면의 중앙에 오도록 스크롤.

## 확대/축소 동작

- `=`나 하단 바의 `+` 버튼: 확대.
- `-`나 하단 바의 `-` 버튼: 축소.
- `Ctrl` + `Shift` + 마우스 스크롤: 확대/축소.
- 하단 바의 해상도 버튼: 해상도 입력 대화창 보이기.

## 엔트리/샘플 전환

- 마우스 스크롤: 이전/다음 엔트리로.
- `위 방향키`/`아래 방향키`: 이전/다음 엔트리로.
- 하단 바의 `<`/`>` 버튼: 이전/다음 엔트리로.
- `Ctrl` + 마우스 스크롤: 이전/다음 샘플로.
- `Ctrl` + `위 방향키`/`아래 방향키`: 이전/다음 샘플로.
- 하단 바의 `<<`/`>>` 버튼: 이전/다음 샘플로.
- `Ctrl` + `G`나 하단 바의 엔트리 번호 버튼: `엔트리 이동...` 대화창 보이기.

## 엔트리 상태 표기

- `J`나 엔트리 상단 바의 `태그 추가` 버튼: 엔트리의 태그 편집.
- `K`나 엔트리 상단 바의 `중요` 버튼: 엔트리의 `중요` 상태 전환.
- `L`이나 엔트리 상단 바의 `완료` 버튼: 엔트리의 `완료` 상태 전환.

### 상태 표기 설정

`설정` -> `환경설정` -> `에디터` -> `엔트리 상태 표기` 에서 설정을 변경해, 필요하지 않은 항목을 숨길 수 있어요.

## 사전편집 동작

`설정` -> `환경설정` -> `에디터` -> `사전편집 동작` 에서, 엔트리 편집 후 자동으로 이어질 동작을 설정할 수 있어요. :

- 다음 엔트리로 이동
- 편집된 엔트리에 자동으로 `완료` 표시 (기본으로 활성화)

## 빠르게 일괄 편집 플러그인을 사용하는 법

- `F1`~`F8`: 상응하는 일괄 편집 플러그인 실행. 사용하려면 `도구` -> `일괄 편집` -> `슬롯 설정...` 에서 설정을 조정해 주세요.
  플러그인에 관한 자세한 내용은 [플러그인](../customization/plugins.md)에서 확인해 주세요.
