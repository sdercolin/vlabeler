# 기타 오디오 형식 지원

`ffmpeg`를 통해 더 많은 오디오 형식을 사용할 수 있어요. [공식 사이트](https://ffmpeg.org/download.html)에서 `ffmpeg`를 설치한
후, `설정` -> `환경설정` -> `차트` -> `지원되는 오디오 형식`에서 `ffmpeg` 실행 파일의 경로를 지정해 주세요.

맥/리눅스를 사용할 경우, 시스템 경로나 `bin`에 `ffmpeg`를 설치해 기본 경로의 `ffmpeg`가 동작할 수 있게 해 주세요.
