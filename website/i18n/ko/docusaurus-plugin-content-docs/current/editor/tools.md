# 도구 설명서

하단의 도구들이 제공됩니다.
`편집` -> `도구`의 단축키나 메뉴 항목으로 도구를 전환하거나, `외형` -> `도구바 표시`를 통해 도구바를 표시해 도구를 전환할 수
있어요.

## 커서 도구

마커를 드래그할 때 사용하는 일반적인 도구에요.

## 가위 도구

클릭된 위치를 기준으로 엔트리를 두 부분으로 쪼개는 도구에요. [다중 편집 모드](./multi-entry-editing.md)에서 새 라벨을 만드는
용도로 주로 사용됩니다.

올바른 위치를 가위 도구로 클릭했을 때 기본적으로 다음과 같은 일이 일어나요. :

1. 잘린 영역의 첫 번째 부분이 재생되요. 음소 확인의 용이함을 위함이에요.
2. 첫 번째 부분의 이름을 입력하는 상자가 에디터에 표시됩니다.
3. `Enter`를 눌러 입력을 확정하거나, `Esc`를 눌러 취소할 수 있어요.
4. 클릭된 지점 밖으로 커서를 옮겨도 입력이 확정됩니다.
5. 자르기가 끝났습니다. 첫 번째 부분은 입력된 이름을 사용할 것이고, 두 번째 부분은 자르기 전부터 있던 원래의 이름을 사용할
   거에요.
6. 에디터가 첫 번째 부분이 속한 엔트리로 이동합니다.

단일 편집 모드에서의 이름 입력은 에디터 내부가 아닌, 대화창을 통해 이루어져요.

가위 도구의 커스텀은 `환경설정` -> `에디터` -> `가위`에서 가능해요.

## 손바닥 도구

에디터 안에서 드래그하면 캔버스를 스크롤해 주는 도구에요.

## 재생 도구 \{#playback}

마우스 클릭이나 드래그를 통해 현재 샘플 파일에서 특정 범위를 재생할 수 있게 해주는 도구에요.
기본적으로 하단의 동작들이 지원됩니다. 사용되는 키는 `설정` -> `환경설정` -> `단축키` -> `마우스 입력`에서 변경할 수 있어요.

- 왼쪽 클릭: 클릭된 위치 ~ 끝까지 재생해요.
- 오른쪽 클릭: 클릭된 위치 ~ 현재 화면에 표시된 영역의 끝까지 재생해요.
- `Shift` + 왼쪽 클릭: 처음 ~ 클릭된 위치까지 재생해요.
- `Shift` + 오른쪽 클릭: 현재 화면에 표시된 영역의 시작 ~ 클릭된 위치까지 재생해요.
- `Ctrl` + 왼쪽 클릭 & 드래그: 드래그된 범위의 오디오를 재생해요.
- `Ctrl` + `Shift` + 왼쪽 클릭 & 드래그: 드래그된 범위의 오디오를 반복해서 재생해요.
