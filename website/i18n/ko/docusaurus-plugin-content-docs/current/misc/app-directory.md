# 앱 폴더 위치 변경

vLabeler는 커스텀 라벨러, 플러그인, 앱 설정, 로그 등의 유저 데이터를 앱 폴더에 저장해요. 기본 위치는 `~/vLabeler` (macOS에서는
`~/Library/vLabeler`)입니다.

앱을 실행하기 전에 환경 변수 `VLABELER_APP_DIR`를 폴더의 절대 경로로 설정하면, 이 위치를 변경할 수 있어요. 폴더가 없으면
자동으로 만들어져요. 값이 유효하지 않으면 기본 위치가 사용됩니다.

기존 데이터는 자동으로 옮겨지지 않아요. 현재 설정을 유지하려면, 원래 앱 폴더의 내용을 새 위치로 직접 복사해 주세요.
