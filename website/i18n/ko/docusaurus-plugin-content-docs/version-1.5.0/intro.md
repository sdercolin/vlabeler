# vLabeler

`vLabeler`는 다음 목표를 따르는 오픈소스 음성 라벨링 프로그램이에요.

- 현대적이고 유연한 UI/UX
- 다양한 음성합성엔진에 맞춘 커스텀이 가능한 라벨링 환경
- 높은 성능 보장, 크로스 플랫폼 지원

**도움, 피드백, 오류 제보 등은 [디스코드](https://discord.gg/yrTqG2SrRd)로 문의해 주세요.**

## 데모 영상

데모 영상(영문)은 [유튜브](https://youtu.be/xFX8SRrJEzM)와
[비리비리](https://www.bilibili.com/video/BV1Ve4y1S7FF)에서 볼 수 있어요.

초기 버전이었던 1.0.0-beta1의 영상으로, UI가 최신 버전의 vLabeler와 많이 다를 수 있어요.

## 이 문서 활용법

- vLabeler가 처음이라면 [설치](./getting-started/installation.md)와
  [라벨러 선택하기](./getting-started/choosing-a-labeler.md)부터 시작해 보세요.
- 이미 편집 중이라면 [키보드/마우스 동작](./editor/key-actions.md)을 비롯한 에디터 항목의 페이지들에서 키보드/마우스 동작, 도구,
  엔트리 탐색에 관해 확인할 수 있어요.
- 새로운 라벨 형식을 지원하고 싶거나 작업을 자동화하고 싶다면
  [라벨러](./customization/labelers.md)와 [플러그인](./customization/plugins.md)을 읽어 보세요.
- 문제가 있다면 [문제 해결](./troubleshooting.md)을 확인하거나
  [디스코드](https://discord.gg/yrTqG2SrRd)에서 질문해 주세요.
