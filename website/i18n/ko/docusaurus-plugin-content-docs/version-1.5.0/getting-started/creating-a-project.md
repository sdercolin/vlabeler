# 프로젝트 만들기

1. `새 프로젝트...`를 눌러 주세요.
2. `샘플 폴더`를 샘플 파일들이 들어 있는 폴더로 설정합니다.
3. `프로젝트 이름`을 원하는 이름으로 바꿔 주세요.
4. 라벨러를 선택하세요. 무슨 라벨러를 써야 할지 모르겠다면, [라벨러 선택하기](./choosing-a-labeler.md) 항목을 읽어 봅시다.
5. 프로젝트 생성 방식을 선택해 주세요. 보통은 `기본`을 선택하면 무방합니다.
6. (프로젝트 생성 방식에서) `파일`을 선택하고 원하는 단일 파일의 경로를 설정하면 입력 파일을 사용할 수 있어요. (라벨러에 따라
   `파일` 선택지가 없을 수도 있어요.)
7. (프로젝트 생성 방식) `템플릿 생성기`를 선택하고 원하는 플러그인을 지정하면, 플러그인으로 템플릿을 생성할 수 있어요.
8. `완료`를 누르고 라벨 편집을 시작합시다.
9. 메뉴에서 `내보내기`를 누르면, 편집된 라벨 파일을 출력할 수 있어요.

`고급 설정`을 누르면, 접혀 있던 더 많은 설정 메뉴들이 나타나요. 라벨러/플러그인이 제공하는 고유 설정 메뉴들도 있으니, 추가적인
커스텀을 원한다면 관련 내용들에 관해 추가로 알아봅시다.
