# アプリディレクトリのカスタマイズ

vLabeler は、カスタマイズされたラベラー、プラグイン、アプリ設定、ログなどのユーザーデータをアプリディレクトリに保存します。デフォルトでは `~/vLabeler`（macOS では `~/Library/vLabeler`）です。

アプリを起動する前に、環境変数 `VLABELER_APP_DIR` にディレクトリの絶対パスを設定することで、この場所を変更できます。ディレクトリが存在しない場合は作成されます。値が無効な場合は、デフォルトの場所が使用されます。

既存の内容は自動的に移行されません。現在の設定を引き継ぎたい場合は、元のアプリディレクトリの内容を新しい場所に手動でコピーしてください。
