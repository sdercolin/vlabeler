# vLabeler

`vLabeler` はオープンソースの音声ラベリングアプリケーションで、次のことを目指しています。

- モダンで流暢な UI/UX
- さまざまな種類の音声生成ソフトウェアで使用される、カスタマイズ可能なラベル付けプロセス
- マルチプラットフォームをサポートする高性能

**ヘルプ、提案、問題レポートなどについては、[Discord](https://discord.gg/yrTqG2SrRd) にて承っております。**

## このドキュメントの使い方

- vLabeler を初めて使う方は、[インストール](./getting-started/installation.md) と
  [ラベラーを選ぶ](./getting-started/choosing-a-labeler.md) から始めてください。
- すでに編集を始めている方は、[キーボード/マウス操作](./editor/key-actions.md) をはじめとするエディタのセクションで、
  キーボード/マウス操作、ツール、エントリの移動について確認できます。
- 新しいラベル形式をサポートしたい場合や、作業を自動化したい場合は、
  [ラベラー](./customization/labelers.md) と [プラグイン](./customization/plugins.md) を参照してください。
- 問題が発生した場合は、[トラブルシューティング](./troubleshooting.md) を確認するか、
  [Discord](https://discord.gg/yrTqG2SrRd) でお問い合わせください。
