# 集成视频

您可以将具有相同名称和时长的视频附加到采样文件，并在编辑时观看该视频。
例如：

```
（采样文件夹）
    - 1.wav
    - 1.mp4
    - 2.wav
    - 2.webm
```

**您需要安装 VLC 才能使用此功能。**您可以从[这里](https://www.videolan.org/vlc/index.html)下载该应用。

请注意，即使在 Apple Silicon mac 上，如果您使用的是从 [Releases](https://github.com/sdercolin/vlabeler/releases)
页面下载的应用程序，您也需要安装 `macOS` 版本，而不是 `macOS (AppleSilicon)` 版本。

使用快捷键 `Ctrl` + `V` 或 `Ctrl` + `Shift` + `V` 在左下角或新窗口中打开附加的视频。
视频将静音地与采样文件一起播放。
