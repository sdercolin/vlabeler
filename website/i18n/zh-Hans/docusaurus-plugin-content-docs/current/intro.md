# vLabeler

`vLabeler` 是一个开源的语音标注应用程序，旨在提供：

- 现代，流畅的 UI/UX
- 可定制的标注流程，以供多个语音合成软件使用
- 高性能的多平台支持

**如需帮助、建议、问题报告等，请加入我们的 [Discord](https://discord.gg/yrTqG2SrRd)。**

## Demo 视频

Demo 视频（英语）发布于 [YouTube](https://youtu.be/xFX8SRrJEzM)
和 [bilibili](https://www.bilibili.com/video/BV1Ve4y1S7FF)。

请注意，由于此演示视频基于 1.0.0-beta1，部分 UI 可能与最新版本不同。

## 如何使用本文档

- 第一次使用 vLabeler？请从 [安装](./getting-started/installation.md) 和
  [选择标注器](./getting-started/choosing-a-labeler.md) 开始。
- 已经开始编辑了？请参阅以 [键盘/鼠标操作](./editor/key-actions.md) 开始的编辑器章节，
  了解键盘/鼠标操作、工具和条目导航。
- 想要支持新的标注文件格式，或自动化您的工作流程？请参阅
  [标注器](./customization/labelers.md) 和 [插件](./customization/plugins.md)。
- 遇到问题？请查看 [疑难解答](./troubleshooting.md)，或在
  [Discord](https://discord.gg/yrTqG2SrRd) 中提问。
