# 多条目编辑模式

对于采用连续模式的标注器（[例](../getting-started/choosing-a-labeler.md#working-on-audio-labels)），你可以在单条目编辑模式和多条目编辑模式间切换。
在多条目编辑模式下，同一采样文件中的互相连接的条目将会被全部显示在屏幕上。您不需切换条目就可以编辑它们。

连续模式的编辑器默认启用多条目编辑模式。您可以点击底部栏中央的 `单/多条目编辑` 按钮来切换。

在多条目编辑模式下，条目的名称会显示在编辑器顶端。您可以通过点击它们执行以下操作：

- 点击：重命名条目
- 长按：转到条目

您还可以在 `设置` -> `偏好设置` -> `编辑器` -> `单击跳转到条目`（默认关闭）中启用该选项，启用后在画布上单击某个条目的主体
即可将其设为当前条目。单击边界或参数线仍会开始拖动，不会切换当前条目。
